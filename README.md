# Олена Мовчан · Простір твоїх змін

Український інтерактивний освітній квіз для самоспостереження за реакціями в конфлікті: Жертва, Рятівник, Переслідувач (Агресор).

## Структура сторінки

Головний екран → підхід → практики для себе → стосунки → маршрут змін → програми та клуб → короткий квіз → пояснення та контакт. Структура адаптована за сторінкою Людмили Бойко; тексти, назви й контакти належать сторінці Олени. Мініпрактики розгортаються без завантаження файлів.

## Можливості

- 9 коротких авторських запитань, 3 відповіді («Рідко», «Іноді», «Часто»), 3 твердження на роль.
- Індикатор прогресу, повернення до відповідей, клавіші 1–3.
- Окремі бали 0–6 за кожною роллю, обробка низьких та однакових результатів.
- Пояснення, запитання для самоспостереження, приклади фраз, друк результату.
- Завершальний блок методу Олени Мовчан: тримісячна програма «90 днів до цілі» та закритий клуб-спільнота «Простір твоїх змін».
- Адаптивний дизайн, клавіатурна навігація, повага до prefers-reduced-motion.
- Без бекенду, зовнішніх бібліотек, аналітики, форм збору контактів та збереження відповідей.

## Локальна перевірка

Потрібен Node.js 18+ для тестів. Запустіть `node --test tests/scoring.test.mjs`.
Для перегляду можна запустити `python3 -m http.server 8000` у корені проєкту та відкрити http://localhost:8000.
Файли ES modules слід відкривати через HTTP-сервер, а не як file://.

## Зміст і підрахунок

Першоджерело концепції: Karpman, S. (1968). Fairy tales and script drama analysis. Transactional Analysis Bulletin, 7(26), 39–43.
Посилання: https://karpmandramatriangle.com/dt_article_only.html

Запитання та правила підрахунку створені для цього квізу; вони не є оригінальним тестом Карпмана й не проходили психометричної валідації. До 1 бала включно за всіма шкалами — без провідної ролі. Різниця не більш ніж 1 бал від максимуму — кілька близьких сценаріїв. Ці межі є умовним редакційним правилом і відкрито пояснюються на сайті.

Квіз не діагностує стан, не визначає особистість, не встановлює причину конфлікту й не підходить для оцінки насильства. За насильство відповідає той, хто його чинить.

Картки програми та клубу містять лише надані назви й формати. Кнопки в обох картках та посилання у футері ведуть у наданий Instagram Олени: https://www.instagram.com/olena.movchanpro/. Посилання відкриваються в новій вкладці. Ціни, умови та характеристики методу не вигадувалися.
